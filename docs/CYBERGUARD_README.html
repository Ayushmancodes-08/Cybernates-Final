1. Executive Overview & Problem Statement

Modern state and educational infrastructures face attacks that target two distinct planes: - The Technology Layer: Port sweeps, SYN floods, credential stuffing, SSH password spraying, API abuse. - The Human Layer: Spoofed SMS notifications (Smishing), spear-phishing emails (BEC), QR payment traps (Quishing), cloned executive voices (Voice Deepfakes), and synthetic keynote video manipulation.

Traditional firewalls only monitor network packets, remaining blind to human-targeted multimodal deception. CyberGuard bridges this gap by unifying network telemetry with computer vision, acoustic spectral processing, graph analytics, and explainable generative AI into a single autonomous Security Operations Center (SOC) platform.

2. Core Architectural Principle

                    AI ADVISES  ───►  DETERMINISTIC POLICY ENFORCES

[!IMPORTANT] Why we do NOT allow Large Language Models to directly execute firewall commands: LLMs are probabilistic, prone to hallucinations, and vulnerable to prompt injection. In CyberGuard: 1. AI Models (KNN, CNN, Transformers, GNN, Qwen 2.5) inspect, classify, score, correlate, and explain threats. 2. Deterministic Policy Engine evaluates mathematical risk thresholds, verifies constraints, synthesizes temporary nftables rules with TTL expiration, and verifies kernel-level Netlink receipts.

4. AI Processing & Feature Extraction Pipeline

A. SMS & Smishing Pipeline (backend/main.py)

  1. Telecom DLT Header Verification: Checks sender ID against the official telecom regulatory registry (flags unauthorized headers such as OKCL-GOV, OKCL-STUDENT).
  2. Urgency & Coercion NLP Classifier: Scores psychological pressure phrases ("within 2 hours", "immediate de-registration", "bank KYC").
  3. URL Evasion Extraction: Extracts embedded shortlinks and measures Shannon entropy.

B. Image & QR Quishing Pipeline (components/multimodal/QRCodeInspector.tsx)

  1. Matrix Decoding: Decodes concealed QR barcode payloads using OpenCV / pyzbar.
  2. Computer Vision OCR: Tesseract OCR extracts surrounding notice text from promotional posters.
  3. Destination Reputation: Analyzes domain age (e.g. registered 3 days ago), free Let's Encrypt SSL certificates, and typosquatting.

C. Audio & Voice Deepfake Pipeline (components/multimodal/AudioWaveformVisualizer.tsx)

  1. Acoustic Spectrogram Transform: Audio converted to 128-band Log-Mel Spectrogram.
  2. Neural Vocoder Detection: Detects sharp high-frequency roll-off above $8,150\text{ Hz}$ typical of HiFi-GAN and DiffWave synthesizers.
  3. Prosody Variance ($F_0$): Measures pitch inflection; cloned voices exhibit robotic flatlines ($\sigma < 5\text{ Hz}$).
  4. Biometric Distance: Cosine distance comparison against enrolled executive voice embeddings.

D. Video Deepfake Pipeline (components/multimodal/VideoFrameAnalyzer.tsx)

  1. Facial Seam Extraction: Evaluates 120 timeline frames for Gaussian boundary artifacts around the jawline.
  2. Blinking Rate Frequency: Flags abnormal eye-aspect ratio rates (e.g., 1.2 blinks/min vs. natural human 14 blinks/min).
  3. Phoneme-to-Viseme Synchronization: Flags temporal phase lag between spoken audio and lip movements.

8. Quickstart: Local Installation & Execution

Prerequisites

  • Python 3.11+
  • Node.js 20+ and npm
  • Windows, Linux, or macOS

1. Backend Setup

# Navigate to backend
cd a:/Cybernates/backend

# Install dependencies
pip install fastapi uvicorn pydantic python-jose argon2-cffi requests

# Launch backend daemon
python -m uvicorn main:app --host 127.0.0.1 --port 8000

Backend API Docs will be available at: http://127.0.0.1:8000/docs.

2. Frontend Setup

# Navigate to frontend
cd a:/Cybernates/frontend

# Install dependencies
npm install

# Start Vite dev server
npm run dev -- --host 127.0.0.1 --port 5173

Frontend UI will be live at: http://127.0.0.1:5173/.
